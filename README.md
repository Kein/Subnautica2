# Subnautica2
UE project SDK for Subnautica2

# Engine changes
This project was made to be compatible with Launcher UE, therefore, a few shortcuts
were used.
Source Engine changes will/*may* come later, for now just base project.

For now, search for "FIXME" if you want to see these changes or workarounds

# Game plugins and modules
Most of the empty plugins that have no reflection data are deleted/skipped (ueseless)
Some of the plugins and modules disabled in project file, feel free to re-enabel if you need them.

# Usage and building

0. It is assumed you have UE5.6 installed and the build toolchain as well
1. Clone the project
2. Install FMODStudio 2.03.09 plugin for Unreal: https://www.fmod.com/download#plug-ins (replace the empty folder)
3. Install Sentry: https://github.com/getsentry/sentry-unreal/releases (same as above)
4. Build the game project
